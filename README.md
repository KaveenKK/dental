# Nevengi Dental Recall

Personalised recall and communication systems for UK dental practices — stop losing revenue to missed calls, texts, and no-shows.

## Quick Start

Open `index.html` in your browser, or run a local server:

```bash
npx serve .
```

## Customisation

- **Brand**: Nevengi Dental Recall (logo placeholder in header/footer)
- **Email**: support@nevengi.com
- **Pricing**: From £150/month — edit cards in `index.html`
- **Enquiry wizard**: Multi-step flow in `#enquiry` — logic in `js/main.js`
- **Colours**: CSS variables at the top of `css/styles.css`

## Structure

```
dental/
├── index.html       # Landing page + interactive enquiry wizard
├── css/styles.css   # Styles
├── js/main.js       # Menu, scroll reveal, enquiry wizard logic
└── README.md
```
